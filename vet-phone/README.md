# 동물병원 전화응대 도우미 (웹앱)

설치 없이 `index.html` 파일 하나만 있으면 됩니다. 인터넷 연결도 필요 없습니다.

## 쓰는 법
1. `index.html`을 병원 컴퓨터 바탕화면 등에 복사
2. 더블클릭 → 크롬/엣지에서 열림 (즐겨찾기 해두면 편함)
3. **⚙️ 설정에서 가격을 우리 병원 가격으로 꼭 수정** (처음 들어있는 가격은 예시)

## 기능
- **건강검진**: 베이직·스탠다드·프리미엄(강아지)·프리미엄(고양이). 패키지를 누르면 검사 항목 표시, 한눈에 비교표
- **건강검진 / 스케일링 / 중성화**: 종·성별·나이·몸무게 입력 → 금액 바로 표시, 추가 항목 체크, 내역 복사
- **정보 검색**: 안내문(진료시간, 금식 등) 검색. 초성 검색 가능 (`ㅈㅅㅎ` → 중성화)
- **설정**: 가격표·추가 항목·안내문 편집, 항목 추가(예방접종, 미용 등)
- **백업**: 데이터는 그 컴퓨터 브라우저에 저장됨. 백업 파일로 내보내서 다른 컴퓨터에서 불러오기

## 가격표 규칙
- 조건(종류·종·성별·몸무게·나이)에 맞는 줄이 **모두 더해짐**
- 빈 칸 = 상관없음, 범위는 "이상 ~ 미만"

## 단축키
`/` 검색 · `Esc` 처음 화면
